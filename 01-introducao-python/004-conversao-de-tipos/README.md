# Exercício 004

## Objetivo

Escreva um programa que converta um valor float em int e outro valor int em float. Exiba os 
resultados das conversões e explique a diferença entre conversão explícita e implícita. 

## Conceitos praticados

- Este exercício demonstra a conversão de tipos em Python: 

- Conversão explícita: De float para int usando a função int(). Nesse caso, o valor decimal é 
truncado (a parte decimal é descartada). 
 
- Conversão implícita: De int para float. Em Python, essa conversão ocorre automaticamente 
durante operações que envolvem tipos mistos, sem perda de informação. 
 
- Este exercício reforça o conceito de conversão de tipos em Python e mostra como a 
conversão explícita pode resultar em perda de precisão, enquanto a conversão implícita 
preserva o valor original.
