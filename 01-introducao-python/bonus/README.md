# Exercício Bonus

## Objetivo

EXERCÍCIO 1: Crie um programa que exiba a mensagem "Olá, Mundo!" na tela.

EXERCÍCIO 2: Escreva um programa que solicite o nome do usuário e exiba uma saudação personalizada.

EXERCÍCIO 3: Desenvolva um programa que demonstra o uso correto da indentação em uma estrutura condicional.

EXERCÍCIO 4: Crie um programa que solicita dois números ao usuário e exibe a soma deles.

EXERCÍCIO 5: Escreva um programa que calcula a idade do usuário com base no ano de nascimento fornecido.

## Conceitos praticados

Neste exercício foram reforçados os fundamentos da linguagem Python, incluindo a utilização das funções print() e input(), criação e manipulação de variáveis, conversão de tipos de dados (int(), float() e str()), operações aritméticas, formatação de strings, além da importância da indentação e da estrutura básica de um programa. Esses conceitos formam a base para o desenvolvimento de aplicações mais complexas.
