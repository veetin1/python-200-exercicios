# 🐍 Python - 200 Exercícios

Bem-vindo ao meu repositório de estudos!

O objetivo deste projeto é resolver **200 exercícios de Python**, evoluindo do nível iniciante ao avançado enquanto desenvolvo uma base sólida em programação.

## Objetivos

- Aprimorar a lógica de programação
- Consolidar os principais conceitos da linguagem
- Praticar boas práticas de desenvolvimento
- Criar consistência através da prática diária
- Registrar minha evolução ao longo do tempo

## Regras do desafio

- Resolver todos os exercícios utilizando apenas Python.
- Não utilizar Inteligência Artificial para resolver os problemas.
- Pesquisar documentação oficial quando necessário.
- Manter os códigos organizados e documentados.
- Sempre buscar uma solução própria antes de consultar qualquer referência.

> **Observação:** Este README foi o único conteúdo criado com auxílio de IA. Todo o restante do repositório (código, soluções e lógica) será desenvolvido por mim.

## Organização

Cada pasta representa um conjunto de assuntos.

```text
01-fundamentos

03-lacos
04-funcoes
05-colecoes
06-poo
07-arquivos
08-banco-de-dados
```

Dentro de cada pasta, os exercícios serão numerados sequencialmente.

Exemplo:

```text

    exercicio-002/
    exercicio-003/
```
