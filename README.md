# 🐍 Python - Minha Jornada de Estudos

Bem-vindo ao meu repositório de estudos!

Este repositório reúne minha evolução em Python por meio de exercícios, desafios e projetos desenvolvidos ao longo da minha jornada de aprendizado e aperfeiçoamento.

A primeira etapa consiste na resolução de **200 exercícios**, organizados por nível de dificuldade e por assunto. Após essa fase, novos desafios e projetos serão adicionados continuamente, transformando este repositório em um histórico da minha evolução técnica.

## Objetivos

- Aprimorar a lógica de programação.
- Consolidar os principais conceitos da linguagem.
- Explorar diferentes formas de resolver problemas.
- Desenvolver boas práticas de programação.
- Documentar minha evolução ao longo do tempo.
- Construir um repositório de consulta e referência.

## Regras do desafio

- Resolver os exercícios utilizando apenas Python.
- Não utilizar Inteligência Artificial para resolver os problemas.
- Consultar documentação oficial e outras referências quando necessário.
- Manter os códigos organizados e documentados.
- Sempre desenvolver uma solução própria antes de pesquisar outras abordagens.

> **Observação:** Este README foi o único conteúdo elaborado com auxílio de IA. Todo o restante do repositório (código, soluções, documentação e anotações) será desenvolvido por mim.
